## 🌟 주요 기능 (Key Features)

- **🎨 모던 글래스모피즘 & 다크/라이트 테마**: 
  - 세련된 반투명 블러 효과와 부드러운 네온 그라디언트 배경
  - 원클릭 다크/라이트 모드 즉시 전환 (설정 자동 저장)
- **⚡ 강력한 할 일 관리 (Task Management)**:
  - 카테고리(업무, 개인, 공부, 건강, 재정) 및 우선순위(🔥 높음, ⚡ 중간, 🌱 낮음) 설정
  - D-Day 및 마감 임박 알림 뱃지 자동 계산
  - 상세 메모 작성 및 모달을 통한 인라인/상세 수정 기능
- **🔍 실시간 검색 & 스마트 필터**:
  - 단축키 `/`를 통한 인스턴트 실시간 검색
  - 상태별(전체, 진행중, 완료됨, 중요⭐) 및 카테고리별 탭 필터링
  - 등록순 / 마감일순 / 우선순위순 / 가나다순 정렬 지원
- **🖐 드래그 앤 드롭 (Drag & Drop)**:
  - 마우스 드래그로 원하는 순서대로 자유롭게 우선순위 재배치
- **🎉 마이크로 인터랙션 & 축하 효과**:
  - Web Audio API 기반의 가벼운 내장 신디사이저 틱/완료 효과음 (음소거 지원)
  - 할 일 완료 및 100% 달성 시 화려한 컨페티(폭죽) 애니메이션 발사
- **💾 로컬 스토리지 자동 저장 & 백업/복원**:
  - `localStorage`를 통해 브라우저를 닫아도 데이터 영구 보존
  - 상단 메뉴(⋮)를 통한 JSON 파일 데이터 내보내기/가져오기 지원

## 🚀 빠른 시작 (Getting Started)

별도의 패키지 설치나 빌드 과정 없이 웹 브라우저에서 바로 실행할 수 있습니다.

1. 저장소 클론:
   ```bash
   git clone https://github.com/j2big051/ToDoList.git
   ```
2. `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 더블 클릭하여 실행합니다.
